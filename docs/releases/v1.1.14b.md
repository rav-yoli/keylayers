## KeyLayers 1.1.8b

- A frame can use **Ctrl** in **Hold** and **F10** in **Toggle** at the same time. Hold activates the frame while the modifier is pressed. The Toggle column displays the exact shortcut you recorded.
- Any frame can receive a Toggle shortcut directly, including frames with no Hold modifier. A new Toggle without a Hold modifier locks the frame's highlight and leaves its action bindings alone.
- Clear a frame's Toggle shortcut with a right-click. Its Hold assignment remains available. Press the active Toggle shortcut again or use the Neutral key to return to Base.

## KeyLayers 1.1.7b

- Click **Assign…** in the **Toggle** column to enter a shortcut directly for a frame that already has a layer. Choose a layer first for an unconfigured frame.
- The frame switches from Hold to Toggle only after the shortcut is saved. Cancelling capture or declining a shortcut conflict preserves the previous frame configuration.

## KeyLayers 1.1.6b

- Choose a layer in the **Toggle** column to capture its shortcut immediately. Use any supported keyboard key or chord, including **Escape**. Use the **Cancel** button to leave capture.
- Physical Ctrl, Shift, and Alt on their own remain available for Hold. Use them with another key to create a dedicated Toggle shortcut.
- After assigning a Toggle shortcut, KeyLayers prompts for a Neutral key if one is missing. If you skip this step, press the active Toggle shortcut again to unlock it. A frame set to **Hold → Base** becomes active again when no modifier is held.

## KeyLayers 1.1.5b

- When a shortcut is already assigned, KeyLayers names the existing action and asks before moving the shortcut. If a trigger is already used by another frame, the confirmation names the affected frame before moving it.

## KeyLayers 1.1.2b

### Keybindings

- **Assign keybindings** is now a tab in the main KeyLayers window. It enters Edit mode automatically, and the window can still be dragged by its header.
- See the entire Base group at once or focus on one bar. Generate Shift, Ctrl, or Alt shortcuts for configured frames in one click and review them before applying. Keep Alt for self-cast if you use it to cast on yourself.

- Enable **Show keybindings only on active frames** in Settings to hide key labels on inactive KeyLayers action bars. The active bars show the key alone, such as **4** for **Shift+4**. The frame's learning label can show the modifier.
- Read what's new in the **Release notes** tab. **Report an issue** gives you the link to the project's [CurseForge issue tracker](https://legacy.curseforge.com/wow/addons/keylayers-by-rav-yoli/issues).

## KeyLayers 1.1.1b

### Assign your shortcuts from Edit mode

- Once your action bars are in place and saved, open **Edit mode → Assign keybindings**. Choose a **Base** bar, click a button, and press the key you want to use. For example, pressing **Shift+4** records **4**. You can also start from the unmodified keys already assigned to the Base bar.
- Select the bars you want to fill. KeyLayers copies each Base key to the same button slot on those bars and adds their configured modifier or combination. For example, **4** on Base can become **Shift+4** on Totems and **Ctrl+4** on Heals.
- Review changes before applying them. Existing shortcuts for other actions are replaced only when you approve the conflict. Other keys already assigned to the same button are kept. The tool saves native WoW keybindings and includes a shortcut to the game's keybinding menu. Bars without a matching native binding are unavailable. KeyLayers skips combinations that use WoW's configured self-cast modifier.

### Hold mode and existing setups

- Choose **Hold → Base** for the frame you want highlighted when no modifier is held.
- WoW's self-cast modifier can now highlight its own Hold frame alongside another Hold layer. For example, holding **Alt+Ctrl** can highlight both your player frame and your healing bar.
- Existing KeyLayers layouts and profiles saved under the old BartenderGlow name carry over automatically.
