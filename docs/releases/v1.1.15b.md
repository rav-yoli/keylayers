## KeyLayers 1.1.15b

- The frame editor keeps the selected frame, its save status, and the Save button visible while you scroll.
- Click a frame in the game or choose it in the editor. Save, discard, or keep editing when you have unsaved changes.
- Start a new frame with an action-bar or interface preset. Select action bars in the game and set the Hold key, Toggle layer and shortcut, and appearance with a live preview.
- Open the same editor from WoW’s AddOns settings, the minimap button, or `/keylayers`. You can also hide the KeyLayers minimap button from WoW’s AddOns settings.
