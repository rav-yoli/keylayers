## KeyLayers 1.1.10b

- ProfileSync can now discover the current KeyLayers layout as character data. Enable it in ProfileSync's Options, save a setup on the source character, and apply it on another character.
- Existing layouts are migrated automatically. Custom frame Toggle shortcuts travel with the layout and are restored when their keys are free. Enable ProfileSync's Key bindings option for regular WoW bindings and the Neutral key.
